# RBU TBI WordPress Theme

Custom WordPress theme for RBU Technology Business Incubator website.

## Quick Start

1. Copy assets to theme folder (see INSTALLATION.md)
2. Zip the `tbi-theme` folder
3. Upload to WordPress via Appearance → Themes → Add New
4. Activate the theme
5. Create pages with the provided templates
6. Set up navigation menu
